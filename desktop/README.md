# 윈도우용 자리 배치표

`SeatChart-Setup.exe`를 실행해 설치한 뒤 바탕 화면의 **자리 배치표**를 엽니다. Windows 10/11 64비트용입니다. 설치 파일에 전자서명이 없어 Windows에서 게시자를 확인할 수 없다는 안내가 나타날 수 있습니다.

- 인터넷 없이 실행할 수 있습니다. 외부 글꼴을 불러올 수 없으면 컴퓨터의 기본 글꼴로 표시합니다.
- **내보내기 / 불러오기**는 윈도우 파일 창을 열며 마지막에 사용한 폴더를 기억합니다. **파일 → 저장 폴더 열기**로 해당 폴더를 열 수 있습니다.
- **도움말 → 업데이트 확인**에서 GitHub에 공개된 최신 화면과 기능을 받아 적용합니다. 업데이트 후에도 이 컴퓨터의 학생 명단과 배치는 유지됩니다. 미적용 입력 내용은 먼저 적용하세요.
- 프로그램 자체(Electron 실행 환경) 업데이트는 **도움말 → 앱 설치 파일 받기**에서 새 설치 파일을 받습니다.
- 웹사이트에 저장한 자료와 앱의 자료는 별개입니다. 웹사이트에서 JSON으로 내보낸 후 앱에서 불러오면 이어서 쓸 수 있습니다.
- 중요한 배치는 JSON 백업으로 따로 보관하세요.

## 개발 및 빌드

```sh
cd desktop
npm ci
npm test
npm start
npm run dist:win
```

`dist/SeatChart-Setup.exe`에 설치 파일이 만들어집니다. 빌드할 때 루트의 최신 `index.html`을 앱에 포함합니다. `ui/`, `dist/`, `node_modules/`는 생성 파일이므로 커밋하지 않습니다.

앱은 파일 읽기/쓰기만 허용하는 제한된 IPC를 사용하며 Node.js는 화면에 노출하지 않습니다. 업데이트는 `Namkicheol/seat-chart`의 `index.html` 최신 커밋에서만 가져와 사용자가 앱 안에서 적용을 선택하면 설치합니다. 학생 자료를 GitHub로 보내지 않습니다.
